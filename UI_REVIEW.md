# Проверка интерфейса

GUI проверен по применимым правилам Vercel Web Interface Guidelines. Проект
использует нативный Win32 API, поэтому правила HTML, ARIA, браузерной
навигации, touch и CSS к нему не относятся буквально.

## `src/win32_gui.cpp`

✓ Все действия представлены нативными `BUTTON`, а не текстом с обработчиком.

✓ Кнопок только с иконками нет; у каждой есть понятная текстовая подпись.

✓ Поля формы имеют видимые подписи и идут перед контролами в tab order.

✓ Стандартные Win32-контролы сохраняют системную клавиатурную навигацию и
видимый фокус. Код не скрывает focus outline.

✓ Ошибки не замалчиваются: модальное сообщение содержит конкретную причину,
например требуемый формат даты или допустимый диапазон приоритета.

✓ Пустое состояние имеет текст «Выберите задачу» и инструкцию следующего
действия. Отчёты отдельно показывают «Нет данных».

✓ Длинные пользовательские названия ограничиваются предметной моделью;
таблица и панель подробностей выделяют им ограниченную область.

✓ Анимации и автоматически движущийся контент отсутствуют.

✓ Заголовок, пояснение, сводные показатели, действия, таблица и подробности
образуют последовательную визуальную иерархию.

✓ Используется Unicode Win32 API и шрифт Segoe UI с ClearType.

✓ Размер окна можно менять; список и правая панель пересчитывают доступное
место в обработчике `WM_SIZE`.

✓ Операции сохранения и экспорта сообщают результат, а форма после успешного
сохранения закрывается и сразу обновляет данные.

## Ограничения платформы

Win32 GUI не использует HTML `<label>`, `aria-live`, URL-состояние,
`prefers-reduced-motion` и CSS focus selectors. Их аналоги обеспечивают
стандартные оконные контролы, системный message loop и отсутствие анимаций.

Формат даты задан явно как `ГГГГ-ММ-ДД ЧЧ:ММ`, потому что JSON должен быть
детерминированным, а проект рассчитан на русскую учебную демонстрацию. Для
международного продукта формат отображения следует отделить от ISO-формата
хранения.

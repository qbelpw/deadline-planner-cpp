# Тёмный интерфейс Deadline Planner

Обновление от 23 сентября 2026 года. Реализация находится в
`src/win32_gui.cpp`; предметная логика и формат сохранений не менялись.

## Оформление

Нейтральный графитовый фон #1C1D20, поверхности #202226, текст #E8E8EA.
Приглушённый синий #3868A7 выделяет основное действие; янтарный #EFC274 и
коралловый #F48F85 обозначают близкие и просроченные сроки.
Цвет сопровождается текстовым статусом. Шрифт — системный Segoe UI.

Счётчики перенесены в нижнюю строку состояния. Список и панель свойств
образуют единое рабочее поле с разделителем. Заголовок компактный,
отчёты и экспорт оформлены как второстепенные команды. Таблица получила
увеличенные строки, тёмный заголовок, цветовые статусы и выделение выбранной
задачи. При нехватке ширины скрывается колонка типа; тип остаётся в подробностях.

Кнопка создания находится в заголовке, команды выбранной задачи — в панели
подробностей. У кнопок есть наведение, нажатие, фокус и недоступное состояние.
Без выбранной задачи команды выполнения отключены. Текст подробностей можно
прокручивать. Выделение сохраняется при обновлении существующей задачи.

Форма создания использует парные поля проекта/типа и приоритета/оценки.
Подпись дополнительных параметров меняется в зависимости от типа задачи;
для обычного дедлайна поле отключено. Минимальная клиентская область —
1060 × 700 логических пикселей. Message loop использует IsDialogMessageW
для навигации по контролам с клавиатуры.

GDI-шрифты, кисти и список изображений освобождаются. Временные кисти/перья
в отрисовке освобождаются после восстановления предыдущих объектов DC.
Тёмный системный заголовок запрашивается через DwmSetWindowAttribute;
системные диалоги, скроллбары и стрелки комбобоксов зависят от версии Windows.

## Проверено в этой доработке

- Сборка и запуск существующего набора C++-тестов на macOS: успешно.
- Проверка Win32-модуля LLVM-MinGW с `-Wall -Wextra -Wpedantic
  -Wconversion -Wshadow`: без предупреждений.
- Полная кросс-сборка Windows x64 GUI с LLVM-MinGW и Boost 1.87: успешно.
- Импорты exe: системные Windows/UCRT DLL, без отдельных DLL компилятора.
- HTML-предпросмотр: обзор и переключение на форму проверены в браузере.

HTML `docs/design-preview.html` — иллюстрация оформления, не Windows GUI.
Запуск, визуальная проверка Win32, клавиатура, DPI 125–200%, диалоги,
создание/завершение задачи и экспорт на Windows ещё требуют проверки.
Кросс-компиляция не подтверждает эти сценарии во время выполнения.

## Проверка на Windows

1. Запустить `start_demo.bat` и проверить обзор шести демонстрационных задач.
2. Выбрать чек-лист, выполнить пункт, убедиться в сохранении выделения.
3. Открыть создание, перебрать три типа, проверить подписи и доступность поля.
4. Создать задачу, проверить сохранение после перезапуска `start_gui.bat`.
5. Проверить фильтр, пустой список, отчёты, экспорт, Tab/Shift+Tab/Space.
6. Изменить размер окна и масштаб экрана; проверить доступность кнопок формы.
